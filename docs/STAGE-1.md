# Результат этапа 1

Дата: 19 октября 2026 года. Следующий этап ожидает подтверждения пользователя.

## Подготовлено

- Установлены зависимости, сохранён `package-lock.json`.
- Собран стек HTML / Stylus / jQuery / ES-модули / Vite.
- Шапка и подвал подключаются через Nunjucks, страницы формируются из общих данных.
- Полностью заполнены 14 программ: описание, процесс, результат, цена, длительность, возраст, уровень, группа, преподаватель, материалы, подготовка и получение работы.
- Созданы четыре вымышленных преподавателя, семь направлений, FAQ, правила посещения и описание демонстрационных данных.
- Реализованы проверка каталога и 22 адреса технических HTML-страниц.
- Добавлены SQLite-миграция, ограничения вместимости и суммы, таблицы повторных запросов и хешей токенов.
- Создана файловая база `storage/ladno.sqlite` с 44 сеансами. Опорная дата — 19 октября 2026 года; расписание занимает шесть недель и содержит прошедший день для проверки состояния.
- Добавлены README, пример окружения и описание архитектуры.

## Реально выполненные проверки

`node scripts/check-content.mjs` — успешно: 14 программ, четыре преподавателя, семь направлений.

`npm test` — 10 из 10 проверок прошли:

1. Полнота каталога и корректность связей.
2. Отклонение некорректной цены, дублирующегося адреса и неизвестного преподавателя.
3. Московская дата на границе суток UTC.
4. Все программы в расписании, отсутствие пересекающихся занятий.
5. Повтор миграции и наполнения без удаления брони и сдвига дат.
6. Отклонение превышения вместимости и уменьшения её ниже занятого.
7. Отмена освобождает места; повторная отмена не создаёт лишние места.
8. Отклонение неверной суммы и неизвестного сеанса.
9. Уникальность ключа повторного запроса в схеме базы.
10. Сохранение брони после закрытия и повторного открытия SQLite-файла.

`npm run build` — успешно, Vite 7.3.7, 22 HTML-страницы и общие CSS/JS-файлы.

`node scripts/migrate.mjs` — применена одна миграция на файловой базе.

`node scripts/seed.mjs` — первый запуск добавил 44 сеанса, повторный добавил 0; всего осталось 44.

Среда: Windows, Node.js 22.21.0, npm 10.9.4. Установочные скрипты, тесты и сборка запускались с разрешённым выходом из песочницы, поскольку обычный режим блокировал дочерние процессы Windows.

## Ещё не реализовано и не проверялось

Финальный дизайн, изображения, фильтры, галереи, интерфейс расписания, HTTP API, публичная запись и отмена по токену. Конкурентные HTTP-запросы, проверки безопасности API и сквозной сценарий относятся к следующим этапам.

Браузер, визуальные скриншоты и запуск production-сервера на этом этапе не проверялись. Успешная сборка технических страниц не является проверкой готового сайта.
