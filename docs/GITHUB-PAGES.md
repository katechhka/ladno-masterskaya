# Демоверсия на GitHub Pages

Адрес: https://katechhka.github.io/ladno-masterskaya/.

Это самостоятельная статическая копия. Она не обращается к Vercel, Turso,
Telegram или хранилищу фотографий. Каталог и изображения берутся из исходников,
расписание создаётся из отдельной пустой временной базы на дату сборки.
Никакие рабочие брони, контакты, пароли или ключи в сборку не включаются.
Админка и управление бронью отсутствуют. Форма проверяет поля и показывает итог,
но никуда не отправляет и не сохраняет контакты. Используйте вымышленные данные.

Сборка: `npm ci`, затем `npm run build:pages`.
Проверка в установленном Chrome: `npm run pages-demo:check`.
Результат — `dist/`; обычная сборка Vercel использует другую команду.
Перед серверными тестами после проверки демоверсии выполните `npm run build`:
статическая сборка намеренно не содержит серверный manifest и страницы админки.

Workflow `.github/workflows/pages.yml` публикует только `dist/` через официальный
механизм Pages. Запускается после push в main, вручную и по понедельникам для
обновления примерных дат. Рабочие секреты ему не нужны. В настройках репозитория
Pages → Source необходимо выбрать GitHub Actions.
После включения Pages задайте переменную репозитория `PAGES_ENABLED=true`
в Settings → Secrets and variables → Actions → Variables и запустите workflow.
До этого GitHub проверяет сборку, а шаг публикации пропускается.

Локально проверены 24 HTML-страницы, Chrome на 1440/768/360 px, фильтрация,
пустой поиск, валидация, демонстрационный итог, отсутствие запросов к API.
Обычная серверная сборка и 60 серверных тестов также прошли.

9 ноября 2026 года владелец разрешил открыть репозиторий для бесплатной публикации.
Репозиторий публичный, Pages включён в режиме GitHub Actions, переменная
`PAGES_ENABLED=true` настроена. Секреты и рабочие данные не входят в Git.
