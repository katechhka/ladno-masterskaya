# Результат этапа 2

**Архив первой версии.** Этот дизайн отклонён пользователем из-за сходства с hp. Текущая версия полностью переработана; актуальный результат: [STAGE-2-V2.md](STAGE-2-V2.md).

Дата: 19 октября 2026 года. Этап 3 ожидает подтверждения пользователя.

## Что готово

- Визуальная концепция «рабочий стол как журнальный разворот»: бумажный фон, терракота, кобальт, олива, открытые фотографии и тонкие линии.
- Логотип-написание, шапка, подвал, типографика и адаптивная сетка.
- Локальные Literata Variable и Golos Text Variable с кириллицей и латиницей, шесть WOFF2-файлов и две OFL-лицензии.
- Общие БЭМ-стили кнопок, ссылок, полей, ошибок, уведомлений, фильтров, доступности и карточек.
- Видимый фокус, ссылка перехода к содержимому, уменьшение движения по системной настройке.
- Отдельная страница просмотра `/design/`: первый экран, примеры карточек, история пространства, образцы компонентов и раскрывающаяся медиатека.
- 24 отдельных изображения созданы встроенным `image_gen`: первый экран, 14 программ, четыре дополнительных кадра для галерей, пять кадров пространства, материалов и процесса.
- Все результаты просмотрены. Сохранены оригиналы и полные промпты; сторонние фотографии и результаты поиска не используются.
- Подготовлены 148 адаптивных файлов WebP/AVIF размером суммарно 8,51 МБ. Каждый браузер выбирает подходящий формат и размер через `picture`/`srcset`, а не загружает весь набор.
- Для каждого изображения указаны размеры, альтернативный текст и точка кадрирования. Для каждой программы подготовлено по три разных осмысленных кадра галереи.

## Реально выполненные проверки

1. `node scripts/check-images.mjs` — 24 уникальных оригинала, 148 корректных локальных файлов, изображения и галереи всех 14 программ.
2. `node scripts/check-content.mjs` — каталог и ссылки данных корректны.
3. `npm run build` — production-сборка 23 HTML-страниц, Stylus, jQuery и локальных шрифтов проходит без предупреждений.
4. HTTP-запрос к `/design/` — ответ 200.
5. Через Chrome DevTools проверены загрузка шрифтов, выбор AVIF и отсутствие ошибок консоли на странице дизайна.
6. `npm run design:check` — установленный Google Chrome, размеры 1440×1000, 768×1024, 390×844 и 360×800. Нет горизонтального переполнения, ошибок JavaScript, ответов HTTP 400+ и внешних запросов. Все 24 изображения загружаются после раскрытия медиатеки.
7. Клавиатурой проверены фокус ссылки перехода к содержимому и переход по Enter; проверен режим `prefers-reduced-motion`.
8. Сохранены девять скриншотов: полные страницы, видимые области четырёх размеров и медиатека. Просмотрены композиция, типографика, изображения и мобильная адаптация.

При проверке исправлены пути шрифтов в сборке, скрытие ссылки перехода к содержимому на скриншотах и плотность первого экрана на телефоне.

## Границы результата

`/design/` — страница просмотра дизайна, не готовый сайт целиком. Остальные разделы остаются техническими страницами. Фильтры, рабочие галереи программ, расписание и API записи относятся к следующим этапам. Образцы доступности и уведомлений не подтверждают наличие мест или создание брони.

Проверки выполнялись в браузере с указанными размерами, не на физических телефонах. Тесты HTTP-бронирования, конкурентных запросов и production-сервера пока не выполнялись: соответствующая реализация ещё впереди.
