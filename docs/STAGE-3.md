# Результат этапа 3 — страницы и взаимодействия

Дата: 19 октября 2026 года. Сохранён утверждённый дизайн версии 2. Следующий этап — серверная запись — ожидает подтверждения.

## Что реализовано

- Главная: афишный первый экран, переключение материалов, семь направлений, три ближайших доступных сеанса из общей базы, мастерская, шаги посещения, четыре преподавателя, FAQ и честное демонстрационное расположение.
- Каталог: 14 программ, изображения, цены, длительность и возраст; поиск по названию и описанию; направление и возраст; сортировка по цене и длительности в обе стороны; счётчик, сброс и пустое состояние. Состояние сохраняется в URL и восстанавливается при обновлении и переходах назад/вперёд.
- Все 14 детальных страниц: хлебные крошки, три кадра галереи, миниатюры, стрелки, жесты, клавиатура и увеличение в нативном dialog с Escape и возвратом фокуса; процесс, результат, материалы, преподаватель, подготовка, получение работы и связанные программы.
- Выбор сеанса и количества участников, расчёт суммы и переход к просмотру выбора. Для керамики показаны сроки 21–28 дней. На телефоне — компактная панель перехода к выбору даты.
- Расписание: недели, дни, фильтр направления, время Тулы, цена, длительность, возраст и свободные места. Есть дни без занятий, состояния прошедшего/занятого сеанса, отсутствие подходящих дат, загрузка, ошибка и повтор.
- Правила, описание демонстрационных данных, страница просмотра выбранного сеанса и оформленная 404 с правильным HTTP-кодом.
- Общие шаблоны метаданных, шапки и подвала, OG-оформление, favicon. Внутренние адреса полноценные; неизвестный адрес не возвращает главную.

## Расписание и граница этапа

Публичный снимок формируется из существующей SQLite-базы при запуске Vite и сборке. Количество мест вычисляется из подтверждённых записей; контакты, номера броней и токены не экспортируются. Главная, расписание, детальная страница и просмотр выбора используют один модуль данных.

Снимок не является API для живых бронирований. На этом этапе контакты не собираются, запись не сохраняется, подтверждение не имитируется. Это явно написано в интерфейсе. На этапе 4 снимок заменит серверный API с транзакциями, валидацией, защитой повторов, сохранением и отменой брони.

## Реально выполненные проверки

- `npm test`: 13 тестов прошли. Проверены ограничения базы, повтор наполнения, сохранность после открытия SQLite, московские даты и недоступные состояния сеансов.
- `npm run pages:check`: 15 функциональных проверок прошли — каталог, URL, галереи, выбор участников, расписание, ошибочные данные, публичные поля и прямые адреса. Итоговый машиночитаемый отчёт: [pages-check.json](pages-check.json).
- Четыре основные страницы проверены в установленном Chrome на 1440×1000, 768×1024, 390×844 и 360×800. Сохранены 24 скриншота; проверены изображения, отсутствие горизонтальной прокрутки и по одному h1 на странице.
- Проверки пустых/полных сеансов и HTTP 503 используют фикстуры только в тестовом браузере. Рабочая база не менялась.
- Проверены общие данные 14 программ и все 148 адаптивных файлов из 24 изображений.
- Финальная сборка Vite прошла без предупреждений: 23 HTML-страницы и отдельные модули поведения страниц.
- После финальной сборки проверены HTTP-ответы главной, каталога, детальной страницы, расписания, правил, политики и управления записью. Для URL без завершающего слеша работает 308, для неизвестного — 404.

В процессе исправлены цикл обновления Vite, порядок middleware 404 и мобильный порядок галереи/выбора даты. Скриншоты просмотрены для композиции, типографики, отступов и удобства выбора.
