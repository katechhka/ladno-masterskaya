# Управление мастерской

Опубликованная админка: https://ladno-masterskaya.vercel.app/admin/. Облачный доступ сохранён локально в `storage/cloud-admin-access.txt`; он отличается от локального. Особенности облачного хранения, копий и восстановления: [CLOUD.md](CLOUD.md).

Локальная админка: http://127.0.0.1:5173/admin/. Инструкция первого входа ниже относится к локальной SQLite; команда `admin:setup` не меняет облачного владельца.

## Первый вход

Команда `npm run admin:setup` создаёт владельца с логином `owner` и случайным паролем. Данные входа находятся в `storage/admin-access.txt`. Сохраните пароль в менеджере паролей и удалите файл. Он исключён из Git и не доступен через сайт.

Обычный повтор команды не меняет пароль. Если доступ потерян, разработчик с доступом к серверу выполняет `npm run admin:setup -- --reset`: создаётся новый случайный пароль, все старые сеансы входа завершаются. В базе хранится только scrypt-хеш пароля. Общего пароля по умолчанию нет.

Сеанс входа действует восемь часов. По окончании работы нажмите «Выйти». В production нужен HTTPS: cookie входа имеет Secure, HttpOnly и SameSite=Strict.

## Мастер-классы

Нажмите «Добавить программу» или «Редактировать» у существующей. Заполните описание, цену за одного человека, длительность, возраст, размер группы, преподавателя, результат, материалы, подготовку и получение работы. Шаги процесса и материалы вводятся по одному пункту в строке: минимум три шага и четыре материала.

Для новой программы укажите свободный адрес латиницей с дефисами. Он сохраняется при последующих переименованиях, чтобы ссылки не ломались. Выберите обложку, от двух до шести разных фотографий для галереи и минимум две рекомендуемые программы.

В блоке «Свои фотографии» выберите до шести JPEG, PNG или WebP с компьютера, добавьте описание каждого снимка и нажмите «Загрузить фотографии». Максимум — 10 МБ и 40 мегапикселей на файл, минимум 480 × 320 пикселей. SVG и анимация не принимаются. Сервер создаёт уменьшенные WebP/AVIF и удаляет EXIF и другую исходную метаинформацию. Используйте снимки, которые вправе публиковать.

Загруженные фотографии добавляются в общую медиатеку и отмечаются в галерее; первая выбирается обложкой. Проверьте выбор: в галерее должно остаться от двух до шести кадров. После этого сохраните программу. Если сохранение программы не произошло, успешно загруженные фотографии остаются в медиатеке и доступны при следующем открытии. Общее ограничение загрузок — 500 фотографий; удаление файлов из медиатеки пока не реализовано, чтобы не ломать существующие галереи.

Нажмите «Сохранить программу». Изменения сразу доступны на сайте, пересборка не требуется. При ошибке поля сохраняются. Если программу успели изменить в другой вкладке, откройте её заново и повторите свои правки на актуальной версии.

Новая цена применяется к новым записям. Уже подтверждённые брони сохраняют сумму. Длительность и вместимость конкретных сеансов меняются отдельно в расписании; изменение стандартных параметров программы не переносит существующие занятия.

Чтобы убрать программу с сайта, отметьте «Скрыть программу в архив» и сохраните. Она исчезнет из каталога и перестанет принимать новые записи; старые брони останутся доступны по персональным ссылкам. Сеансы с участниками автоматически не отменяются. Вернуть программу можно, сняв отметку архива.

## Расписание

Во вкладке «Расписание» выберите день или включите просмотр прошедших занятий. «Добавить занятие» открывает выбор программы, московской даты, времени и количества мест.

Для повторения раскройте «Повторить в другие дни», задайте окончание в пределах шести недель и дни недели. До сохранения показан полный список дат. Первая выбранная дата включена всегда. Если хотя бы одно занятие пересекается с существующим, вся серия отклоняется: частичного сохранения нет.

В существующем сеансе можно изменить время и вместимость, закрыть только новые записи или отменить занятие полностью. Вместимость не может быть меньше уже занятого числа мест. Одновременно в мастерской проходит одно занятие. Прошедшие и отменённые сеансы доступны только для просмотра; для нового занятия создайте новый сеанс.

Сочетание программы и точного времени остаётся уникальным, в том числе в истории отмен. Если такой сеанс уже был отменён, для нового выберите другое время или дату: история не перезаписывается.

Перенос или отмена с действующими бронями требуют подтверждения. При отмене сеанса отменяются его действующие брони. Участники отмечаются во вкладке «Записи» пометкой «Нужно сообщить».

## Записи и связь с участниками

Откройте «Записи» в общей навигации или у конкретного сеанса. Доступны имя, телефон, email, комментарий, количество участников, сумма и статус. Есть поиск, фильтры по дню и статусу. Если найдено больше 200 записей, уточните условия. Поиск русских имён не зависит от регистра и различия «е»/«ё».

«Отменить бронь» отменяет всю запись группы и освобождает места. Повторная отмена не освобождает их ещё раз.

После переноса или отмены **сообщите участникам лично** по указанным контактам. Затем нажмите «Участнику сообщили». Эта кнопка только снимает пометку, а не отправляет сообщение. Текущее подключение Telegram выдаёт подтверждение по запросу посетителя; автоматические уведомления о переносах и отменах не подключены.

## Хранение и обновление

Программы, сеансы, брони, метаданные фотографий, владелец и сеансы входа хранятся в общей SQLite-базе `DATABASE_PATH`. Файлы загруженных изображений — в постоянном каталоге `UPLOADS_DIR` (по умолчанию `storage/uploads`). При перезапуске они сохраняются. Повторное начальное наполнение не перезаписывает каталог хозяйки. JSON-файлы программ используются только для первого импорта.

До обновления сервера разработчик выполняет `npm run backup:create`: команда делает согласованный снимок SQLite и сохраняет все связанные загруженные фотографии. Восстановление выполняется командой `backup:restore` только в новый каталог, с проверкой файлов и очисткой устаревших контактов; входы хозяйки отзываются. Вернутся программы, расписание и пароль владельца на дату копии. Последующие изменения и отзывы нужно сверить вручную до открытия доступа. Подробный порядок: [BACKUP.md](BACKUP.md). Корень проекта, `storage/`, `.env`, резервные копии и файл доступа нельзя публиковать как статические файлы.

Настройка нового преподавателя, направления и общих текстов сайта пока выполняется разработчиком. Это компактная панель одного владельца, без регистрации сотрудников и разграничения ролей.
