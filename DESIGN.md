# Дизайн «Ладно»

Утверждённая визуальная концепция описана в [docs/DESIGN.md](docs/DESIGN.md).
Её сохраняем: афиша мастерской, коллаж материалов, Unbounded для заголовков,
Onest для текста. Источник цветов и размеров — `src/styles/foundations/tokens.styl`;
компоненты используют общие Stylus-блоки. Новых токенов для Pages нет.

Статическая версия использует существующий блок notice для ясного сообщения
о демонстрации на каждой странице. Каталог, фильтры и выбор занятия сохраняют
поведение основной версии. Контакты остаются только в текущем DOM: сеть,
localStorage и sessionStorage для данных формы не используются. Результат
демонстрации явно говорит, что бронь не создана. Админка и управление бронью
не публикуются. Мобильная ширина — от 360 px, видимый фокус и подписи общие.
